ARSLAN KHICHI AI PROMPT ASSISTANT
================================

A professional, responsive front-end website built with:
- HTML
- CSS
- Vanilla JavaScript

No Node.js, npm, React or build process is required.

HOW TO OPEN (WINDOWS)
1. Download this ZIP file.
2. Right-click the ZIP and choose "Extract All...".
3. Open Visual Studio Code.
4. Choose File > Open Folder.
5. Select the extracted "Arslan-Khichi-AI-Prompt-Assistant" folder.
6. Open index.html.
7. You can double-click index.html in File Explorer to open it in your browser.
   For easier development, install the "Live Server" extension in VS Code, then
   right-click index.html and choose "Open with Live Server".

FEATURES INCLUDED
- Responsive dashboard layout with sidebar navigation
- Prompt builder for ChatGPT, Gemini, Claude and other AI tools
- Prompt generation using structured templates
- Prompt library with search and category filters
- Image Studio prompt builder (visual prompt preparation)
- Copy prompt buttons
- Prompt history and favorites stored in this browser using localStorage
- Prompt templates and quick-start suggestions

IMPORTANT ABOUT REAL AI AND IMAGE GENERATION
This ZIP is a front-end website. Its prompt builder creates well-structured prompts
locally in the browser; it does not call ChatGPT/Gemini or generate actual AI images.
Actual AI text responses and image rendering require an AI provider account/API
and a secure server-side or serverless integration. Do not put a secret API key
inside script.js or any browser JavaScript because visitors can view it.

The Image Studio currently prepares a detailed prompt which you can copy into
an image generation service. A later integration step can connect a secure
serverless API without using Node.js on your own computer.
